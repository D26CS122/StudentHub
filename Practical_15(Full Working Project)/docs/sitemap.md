# StudentHub sitemap

- Public: Home (`index.php`), Events (`events.php`), Register (`register.php`), Login (`login.php`)
- Signed-in student: Dashboard (`dashboard.php`), Profile (`profile.php`), Event registration, Logout (`logout.php`)
- Administrator: Admin dashboard (`admin/index.php`), Students (`admin/students.php`), Events (`admin/events.php`), Users (`admin/users.php`), Registrations (`admin/registrations.php`), Audit logs (`admin/audit-logs.php`)
- API: `api/students.php`, `api/events.php`, `api/registrations.php`
- Legacy Practical 1–10 design artefacts/pages remain in their original directories.
